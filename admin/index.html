Add Teacher

Import Roster

Paste rows copied directly from the roster spreadsheet — First Name, Last Name, YSC Email, Grade, in that order. Any other columns (e.g. parent email) are ignored and never imported. Rows with no YSC Email yet are skipped, not blocked — you can re-paste once emails are assigned.

Import Mentor Assignments

Paste rows — Student YSC Email, Mentor — in that order. Mentor can be a teacher's full name or email; it must match a teacher account exactly (no partial/fuzzy matching — an ambiguous or unmatched name is reported as an error, not guessed). The student must already be in the registry (import the roster first if needed). An existing assignment is shown as a change from the current mentor, not silently replaced.

Paste an indented list: an unindented line is a mentor's full name; any indented line under it (any depth, tabs or spaces) is one of their students, also by full name. Both mentor and student names must match exactly one account/registry record — an unmatched or ambiguous name (e.g. two students sharing a name) is reported as an error, never guessed; a name-collision error lists every matching student's email so you can assign that one manually via the form above.
